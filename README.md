# 🚀 Smart Task Manager with AI Priority

An intelligent task manager that automatically detects task priority using AI keyword logic. Built with Flask + HTML/CSS/JavaScript.

## ✨ Features
- **AI Auto Priority**: Detects High/Medium/Low based on keywords like "urgent", "deadline", "ASAP"
- **Complete Tasks**: Checkbox to mark tasks done with strikethrough effect  
- **CRUD Operations**: Add, View, Update, Delete tasks
- **Clean UI**: Color-coded priorities - Red for High, Yellow for Medium, Green for Low
- **Responsive Design**: Works on mobile and desktop

## 🛠️ Tech Stack
- **Backend**: Python, Flask, Flask-SQLAlchemy
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Database**: SQLite
- **AI Logic**: Keyword-based priority detection
